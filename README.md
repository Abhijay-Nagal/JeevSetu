# Team-25 — JeevSetu

A digital hub for BNHS (Bombay Natural History Society) — a RAG-powered
Knowledge Hub, community engagement, gamified daily engagement, and a
research submission channel, all built on FastAPI + Supabase + React.

## Branches

- **`main`** — the contributor-facing app: community engagement, RAG
  Knowledge Hub, rewards/gamification, Publications.
- **`admin_analytics_frontend`** — the staff-only **admin dashboard and
  analytics section**, developed and demoed separately from `main` on
  purpose. See that branch's own `README.md` for setup, the permanent
  admin login, and how it talks to the database.
